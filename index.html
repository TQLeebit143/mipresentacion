Perfil académico UPDS · Bolivia

Soy Génesis Alejandra Flores Tarqui, estudiante de Ingeniería de Sistemas en la Universidad Privada Domingo Savio. Me encuentro en formación continua y combino el estudio con proyectos de desarrollo web, diseño de bases de datos e infraestructura de redes. Disfruto convertir ideas en interfaces claras, accesibles y funcionales, cuidando tanto la lógica como la experiencia de usuario.

Competencias técnicas

C# ASP.NET Core PHP Angular HTML5 CSS3 JavaScript PostgreSQL SQL Server Docker VMware

Datos rápidos

  • Nombre completo: Génesis Alejandra Flores Tarqui.
  • Carrera: Ingeniería de Sistemas, UPDS (Bolivia).
  • Áreas de interés: desarrollo frontend, bases de datos e infraestructura de redes.
  • Arquitectura: HTML único adaptable con Flexbox, WCAG y Service Worker.

Temas de interés Despliega cada área

Desarrollo frontend y experiencia de usuario

Construcción de interfaces con HTML5, CSS3 y JavaScript, cuidando la jerarquía visual, la accesibilidad, los estados de foco y la adaptación a distintos tamaños de pantalla.

Bases de datos y lógica de negocio

Diseño de esquemas relacionales, normalización y consultas en SQL Server y PostgreSQL, además de la validación de datos y la organización de la lógica del lado del servidor con C# y PHP.

Redes e infraestructura

Prácticas de administración en Rocky Linux, conexiones SSH, DNS, virtualización con VMware y despliegue de servicios con Docker como base de mi formación en infraestructura.

Literatura, cine y cultura pop

La lectura y el análisis de historias complementan mi formación técnica: novelas, series, anime y música me ayudan a observar narrativas, personajes y lenguajes visuales que también aplico al diseño de interfaces.
